# camunda-russian-spell-checker

Плагин для Camunda Modeler с проверкой русской орфографии, терминологии и дополнительными инструментами для BPMN-схем.

## Стабильная версия

Текущая стабильная версия: **v0.6.26**.

Готовая сборка хранится в каталоге `releases/`.
## Свежая версия
[Camunda-russian-spell-checker-v0.6.28.zip](https://github.com/xxxpvpgpt-dot/camunda-russian-spell-checker/blob/54cd40228c4c400f26362cf8a244080dcb9090fe/camunda-russian-spell-checker-v0.6.28.zip)

## Политика стабильных версий

Стабильные версии дополнительно фиксируются отдельными Git-ветками вида `stable/vX.Y.Z`, чтобы к ним можно было вернуться независимо от дальнейшей разработки.

## Установка

Распакуйте плагин в:

`%APPDATA%\camunda-modeler\plugins\camunda-russian-spell-checker`

После этого перезапустите Camunda Modeler.
